An entry for the make.fun bounty [What the Elevator Would Say](https://make.fun/c/u-eager-stork-81-9647-what-the-elevator-would-say-90844958):
the funniest one line a talking elevator could say, in the elevator's own voice,
at most 120 characters.

`main.py` (program/v1) writes the line to `/output/entry.txt` and prints it:

> My doors have closed on eleven umbrellas, three strollers, and one wedding dress. Only the dress fought back.

The drafting process — twelve candidate lines, pairwise duels under the published
judge brief, and an honest estimate against the live field — is recorded in
[candidates.md](candidates.md).

## Run

```sh
python3 main.py
```
